10. Design Rules For Development

กฎนี้ใช้เป็น guardrail ให้ AI และทีมพัฒนาออกแบบหน้าจอไปในทิศทางเดียวกัน

ใช้ design token กลางสำหรับสี, spacing, border radius, status badge และ table ทุกหน้า
ทุก module ต้องมี loading, empty, error, permission denied และ read-only state
หน้าทำงานของร้านควรเป็น dense but calm: ตารางอ่านง่าย filter ชัด action ไม่ซ่อนลึก
mobile ต้องมี quick action ที่ใช้งานจริง ไม่ใช่เพียงย่อ layout จาก desktop
